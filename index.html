For developers

1Get credentialsObtain a client ID and an individual API key from AC through an approved channel.
2Integrate server to serverSend XML application requests over HTTPS. Do not embed credentials in browser code.
3Handle both response patternsInspect the XML result, and poll the AC results URL when one is returned.

Production API host

https://api.authorisedcompliance.com

Only documented routes should be used. A separate staging environment may exist, but access and approved testing arrangements must be obtained from AC.
