Integration support

Use your established Authorised Compliance implementation contact for onboarding, credentials, access problems and API incidents. This public documentation intentionally does not publish an unverified support mailbox or SLA.

Include in a technical support request

Item Include?
Approximate timestamp and timezone Yes
HTTP method and AC endpoint path Yes
HTTP status and public error code Yes
X-AC-Request-ID / response request_id Yes
Client ID (only through an approved support channel) When requested
Customer name, DOB, income or application XML No, not in ordinary support tickets
API key, campaign code or encrypted results token Never

Before contacting AC

Check Authentication, Errors and retries and Retrieve results. If a submission timed out, do not resubmit it automatically while the original outcome is uncertain.
