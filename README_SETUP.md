# Authorised Compliance Developer Portal

Static API documentation for Authorised Compliance, published with GitHub Pages.

## Contents

- Developer portal homepage
- Lending API overview, quick start, authentication, submit application, application fields, retrieve results, response codes, errors and retries, security and privacy
- Responsive navigation and documentation search

## GitHub Pages

Publish from the `main` branch repository root using Settings > Pages. Configure `docs.authorisedcompliance.com` as the custom domain and point the authoritative DNS CNAME for `docs` to `Authorised-Compliance-Ltd.github.io`.

## Maintenance

Each documentation page has its own `index.html`. Search results are defined in `assets/search-index.json`; common JavaScript and CSS are in `assets/`.

The repository is public: do not commit secrets, consumer information, internal implementation guides, or third-party platform configuration.
