Changelog

This page records the client-facing changes reflected in this documentation. It is not a substitute for a formal release notice or change approval.

26 October 2026 - Documentation draft

  • Created a consolidated AC Developer Portal suitable for multiple future products.
  • Documented the new POST /post submission path and the current generated AC results-link pattern.
  • Documented client ID/API-key authentication, controlled XML validation, one-step and two-step responses, and secure polling.
  • Marked the proposed root /results alias as unverified/not yet documented as live.

21 October 2026 - Additional submission route

  • A new POST /post API Gateway method was added for another client and connected to the existing production relay.
  • An initial 404 not_found was traced to the relay's route allowlist.
  • The relay routing condition was updated to permit /post alongside /Monevo/api.
  • A follow-up Postman test reported an HTTP 200 response from /post.

Earlier production behaviour

  • The gateway uses AC-managed provider configuration and rewrites accepted results links into AC-controlled polling URLs.
  • The implementation supports lender-response polling and may also receive complete one-step responses, depending on campaign behaviour.

For breaking changes or additional endpoints, obtain confirmation from AC before treating them as available in production.
