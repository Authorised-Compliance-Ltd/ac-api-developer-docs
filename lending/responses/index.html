Response codes
LENDING / BEHAVIOUR

Response codes

Always inspect the XML <result> code after a successful HTTP response. A transport-level 200 OK does not guarantee a loan offer or an accepted application.

Initial submission XML codes

XML result Meaning Client behaviour
10 Application accepted / submitted Read and poll the returned AC results_url
11 Authentication / campaign or IP failure downstream Treat as a rejected application; contact AC if unexpected
12 Invalid application parameters Validate fields and correct request
13 Rejected by business rules Do not auto-resubmit
21 / 22 No lender offers or no eligible lender Show an appropriate no-offer journey
20 Offers found, when supplied as a final/direct response Process offers without assuming a polling URL exists

The source specification enumerates 10, 11, 12, 13, 21 and 22 as initial results; a direct final result (20) has also been observed in this project's live campaign integration. Behaviour can depend on campaign configuration.

Polling XML codes

XML result Meaning
10 Application accepted; results pending
20 One or more offers found
21 All lenders rejected
22 No qualified lender found

Some XML examples may have result=20 while awaiting_response is still greater than zero. Use the progress fields, not the result code alone, to decide whether polling has finished.

Progress fields

XML element Purpose
offer_results/accepted Offers returned
offer_results/rejected Lenders declined
offer_results/awaiting_response Lenders not yet responded

Some early responses may omit optional blocks. Treat missing fields as absent, not necessarily 0, unless this is explicitly agreed in your integration.

Offer handling

Offer payloads may include loan/type, APR, term, repayment, lender details and redirect URLs. Not every product is a standard personal loan. Alternative or credit-building products may omit a conventional APR, loan term or repayment amount.

Do not silently relabel alternative products as personal loans or display blank loan figures as zero. If your customer journey cannot display alternative products, agree the handling with AC.
