PRODUCT / LENDING

Lending API

Use one AC-facing interface for consumer loan application submission and lender-response retrieval. AC authenticates your system and relays requests through its controlled integration.

Integration flow

Client backend→Authorised Compliance Ltd API→Lending platformResponses and any subsequent polling return through AC.

Available functionality

Operation Method Public endpoint Status
Submit a loan application POST https://api.authorisedcompliance.com/post Available
Poll submitted application results GET Use the exact results_url returned by AC Available via returned URL

The pre-existing client-facing submission route is maintained separately for backwards compatibility. New integrations should use the URL specifically assigned by AC.

Important behaviours

  • HTTP success and lending outcomes are different. An HTTP 200 may contain an XML decline or validation result.
  • An application can complete immediately or require polling. Do not assume every initial response includes results_url.
  • Use the returned results link. Poll only the exact HTTPS results_url supplied by AC.
  • Keep credentials server-side. This API is not designed for untrusted browser clients.

Integration sequence

  1. Authentication - configure your AC client ID and API key.
  2. Quick start - perform your first approved request.
  3. Application fields - implement the required data mapping.
  4. Retrieve results - implement AC-mediated polling.
