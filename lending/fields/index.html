Application fields

AC accepts a defined list of application fields and rejects fields not on that list. Additional lending validation applies, including required and conditionally required values.

Important distinction: A field being accepted by AC does not guarantee that an application containing it is valid for the downstream lender marketplace. Follow the required and conditional field guidance below, along with any additional integration requirements provided by AC.

site_url, site_ip, client_ip Required Originating website and customer context

Additional address history, employment, expenditure, banking and consent fields may be needed to access the relevant lender panel or satisfy particular lender rules.

Field format cautions

  • Use integer GBP values where the source specification requires whole pounds.
  • Do not invent a value for a field you have not collected or for which you lack a lawful basis.
  • Phone, income, address and employment rules may vary by lender and should be verified during integration testing.
  • Include affiliate_app_id when available for traceability; use a unique, client-controlled application reference.
  • campaign_code and mode must not be submitted. AC controls them.
