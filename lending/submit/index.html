Submit an application

POSThttps://api.authorisedcompliance.com/post

Send the consumer's application as a UTF-8 XML document from a trusted backend. AC checks the request, supplies its own downstream configuration, forwards the request, and returns the resulting XML.

Request requirements

Item Requirement
Headers X-AC-Client-ID, x-api-key, Content-Type: application/xml
Body Flat XML with supported child elements
Maximum request body The relay enforces a 64 KiB cap
Forbidden fields campaign_code, mode
Unknown or duplicate fields Rejected by AC
Customer data Provide valid, consented values according to the application field requirements

Nested XML elements, attributes, namespace-based fields, mixed content, DTD/entity declarations and other unsafe XML forms are rejected.

Request skeleton

<?xml version="1.0" encoding="UTF-8"?>
<application>
  <affiliate_app_id>YOUR_REFERENCE</affiliate_app_id>
  <loan_amount>5000</loan_amount>
  <loan_purpose>8</loan_purpose>
  <loan_term>48</loan_term>
  <title>1</title>
  <first_name>FIRST_NAME</first_name>
  <last_name>LAST_NAME</last_name>
  <dob>YYYY-MM-DD</dob>
  <marital_status>3</marital_status>
  <mobile_phone>07XXXXXXXXX</mobile_phone>
  <email>CUSTOMER_EMAIL</email>
  <postcode>CUSTOMER_POSTCODE</postcode>
  <building_number>10</building_number>
  <street_name>STREET_NAME</street_name>
  <city>CITY</city>
  <county>COUNTY</county>
  <months_at_address>36</months_at_address>
  <residence_type>2</residence_type>
  <income_source>1</income_source>
  <gross_annual_income>35000</gross_annual_income>
  <rental_mortgage_payments>800</rental_mortgage_payments>
  <terms_consent>1</terms_consent>
  <site_url>https://client.example</site_url>
  <site_ip>203.0.113.10</site_ip>
  <client_ip>198.51.100.10</client_ip>
</application>
Example values: Placeholders, reserved example IP ranges and example domains are not real application data. Include every conditionally required field, use valid consumer details and valid consents, and perform live testing only with approval. The sample must not be sent unchanged.

Example: accepted for processing

<?xml version="1.0" encoding="utf-8"?>
<response>
  <result>10</result>
  <reference>EXAMPLE_REFERENCE</reference>
  <message>Submitted</message>
  <error><code /><desc /></error>
  <results_url>AC_RESULTS_URL_FROM_RESPONSE</results_url>
</response>

AC_RESULTS_URL_FROM_RESPONSE represents the full HTTPS URL supplied by AC. When result=10, use the returned results_url exactly as received: do not construct or replace it.

Example: no eligible offers

<response>
  <result>22</result>
  <reference>EXAMPLE_REFERENCE</reference>
  <message>Rejected</message>
  <error><code /><desc /></error>
</response>

An HTTP 200 with <result>22</result> is a business-level decline, not an HTTP transport failure. See Response codes.
